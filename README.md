# entropy — Генератор криптографически стойких паролей

> **entropy** — быстрый, гибкий и безопасный генератор паролей для командной строки. Написан на Go, использует только стандартную библиотеку и Cobra для CLI.

---

## ✨ Возможности

| Возможность | Описание |
|-------------|----------|
| **CSPRNG** | Источник случайности — `crypto/rand` (подходит для секретов, ключей, токенов) |
| **Гибкие наборы символов** | Строчные, заглавные, цифры, спецсимволы — комбинируй как хочешь или используй `--all` |
| **Множество кодировок** | Raw, **hex**, **base32** (RFC4648, без padding), **base64**, **base62** |
| **Параллельная генерация** | Пул горутин для массового создания паролей |
| **Потоковый вывод** | Прямая запись в stdout или файл — никаких огромных буферов в памяти |
| **Префикс / суффикс** | Добавь статические строки без учёта в длине пароля |
| **Вывод в файл** | `--write-to` с опциональным `--overwrite` |
| **Кроссплатформенность** | Один бинарник, никаких рантайм-зависимостей |

## Быстрый старт

```bash
# Один пароль 32 символа, все наборы
entropy -A

# 10 паролей по 24 символа, только строчные + цифры
entropy -l 24 -r 10 -L -N

# Base64, 32 байта → 44 символа, 5 паролей
entropy -l 32 -r 5 -A --encoding=base64

# В файл с префиксом/суффиксом
entropy -l 20 -r 50 -A --encoding=base62 --prefix="pwd_" --suffix="_2024" -w passwords.txt -o
```

## Справочник флагов

```text
entropy [flags]

Flags:
  -l, --len int            Длина пароля в байтах/символах (по умолчанию 32)
  -r, --repeat int         Количество паролей для генерации (по умолчанию 1)
  -L, --lowercase          Использовать строчные буквы (a-z)
  -U, --uppercase          Использовать заглавные буквы (A-Z)
  -N, --nums               Использовать цифры (0-9)
  -S, --specials           Использовать спецсимволы (!@#$%^&*-_+=)
  -A, --all                Использовать все вышеперечисленные (по умолчанию, если ничего не выбрано)
  -w, --write-to string    Путь к файлу вывода (по умолчанию: stdout)
  -o, --overwrite          Перезаписать файл, если существует
      --prefix string      Префикс к каждому паролю (не учитывается в длине)
      --suffix string      Суффикс к каждому паролю (не учитывается в длине)
      --encoding string    Кодировка вывода: hex, base32, base64, base62
  -h, --help               Показать справку
```

## Наборы символов

| Флаг | Набор | Размер | Энтропия/символ |
|------|-------|--------|-----------------|
| `-L` | `abcdefghijklmnopqrstuvwxyz` | 26 | ~4.7 бит |
| `-U` | `ABCDEFGHIJKLMNOPQRSTUVWXYZ` | 26 | ~4.7 бит |
| `-N` | `0123456789` | 10 | ~3.3 бит |
| `-S` | `!@#$%^&*-_+=` | 12 | ~3.6 бит |
| `-A` | **Все вместе** | **74** | **~6.2 бит** |

> **Расчёт энтропии**: `log2(размер_набора)`. Пароль длины 32 из `-A` даёт ~198 бит энтропии.

## Примеры

### Пароли для людей

```bash
# Классика: 16 символов, все наборы
entropy -l 16 -A

# 5 паролей, 20 символов, строчные + цифры (удобнее вводить)
entropy -l 20 -r 5 -L -N

# С префиксом/суффиксом для идентификации
entropy -l 16 -r 3 -A --prefix="prod-db-" --suffix="-2024"
# prod-db-k9F2mP8qR3vX7wZ1-2024
# prod-db-a1B2c3D4e5F6g7H8-2024
# prod-db-ZyXwVuTsRqPoNmLk-2024
```

### Машинные / API-ключи

```bash
# 32 байта → 64 hex-символа (256 бит)
entropy -l 32 --encoding=hex

# 32 байта → 52 base32 символа (без padding, безопасно для имён файлов)
entropy -l 32 --encoding=base32

# 32 байта → 44 base64 символа (стандарт)
entropy -l 32 --encoding=base64

# 32 байта → ~34 base62 символа (компактно, только алфавит+цифры)
entropy -l 32 --encoding=base62
```

### Массовая генерация в файл

```bash
# 1000 API-ключей, base64, по одному на строку
entropy -l 32 -r 1000 --encoding=base64 -w api_keys.txt -o

# 500 паролей с префиксом, raw charset
entropy -l 24 -r 500 -A --prefix="user_" -w users.txt
```

## Модель безопасности

| Аспект | Реализация |
|--------|------------|
| **Источник случайности** | `crypto/rand` (OS CSPRNG: `/dev/urandom`, `getrandom()`, `BCryptGenRandom`) |
| **Смещение (bias)** | `rand.Int(rand.Reader, n)` — равномерное распределение через rejection sampling (в stdlib) |
| **Память** | Пароли генерируются в горутинах и сразу стримятся в writer — нет полного буфера в RAM |
| **Права файла** | Создаётся с умолчательной umask (обычно 0644). Для секретов сделай `chmod 600` после. |
| **Логирование** | Ничего не пишется в логи, историю или временные файлы |

> **Аудит**: Единственная внешняя зависимость — `github.com/spf13/cobra` (парсинг CLI). Вся криптография — стандартная библиотека Go.
